## Nodes

### device: server
label: server
sub: Linux · Docker · NVIDIA
host: server.tailnet.ts.net
radius: 26

The always-on machine that runs every stack in this repo, plus the backup timer and cloudflared as host services.

### device: laptop
label: Laptop
sub: Tailscale · browser

Uses every private hostname over Tailscale, and runs `./install.sh --host` to manage the server remotely.

### device: phone
label: Phone
sub: Tailscale · apps

Immich app for photo backup, a scanner app syncing into Paperless's inbox, the dashboard in the browser.

### device: ha-box
label: Home Assistant
sub: separate box
host: ha.home.example.com
radius: 15

Home automation on its own machine. Caddy fronts it with HTTPS; its voice assistant uses Ollama and the speech bridge on the server.

> HA must list the server as a **trusted proxy**, or proxied requests get a 400.

### device: nas
label: Backup target
sub: NAS or router USB disk
radius: 14

SMB share holding the nightly backups (`db-dumps/`, `restic-repo/`). Mounted over the LAN, not Tailscale.

### external: tailscale
label: Tailscale
sub: private network

`*.home.example.com` points at the server's Tailscale IP, so every private hostname only works on your tailnet.

### external: cloudflare
label: Cloudflare
sub: DNS · certificates · tunnel

DNS-01 challenges for Caddy's wildcard certificate, and the edge for the tunnel's public hostnames.

### external: visitor
label: Anyone
sub: public internet

People you send a shared album or a download link to. They only ever reach the two public hostnames.

### external: openmeteo
label: Open-Meteo
sub: weather API

Weather widget on the dashboard.

### proxy: caddy
label: Caddy
sub: reverse proxy
host: *.home.example.com
radius: 20

One wildcard certificate, one route per enabled stack, generated by `./lab render`.

### proxy: cloudflared
label: cloudflared
sub: tunnel
radius: 15

Maps each public hostname to one loopback port. Never reaches Caddy or any private route.

> Reads only **/etc/cloudflared/config.yml**; `./install.sh --public` writes it.

### app: homepage
label: Homepage
sub: dashboard
host: dash.home.example.com
radius: 17

A live tile per service, generated from each stack's `homepage.yaml`.

### app: glances
label: Glances
sub: monitor
host: glances.home.example.com

CPU, memory, disks, network, GPU and containers.

### app: immich
label: Immich
sub: photos
host: photos.home.example.com
radius: 19

Photo and video library with face and object recognition.

### app: immich-proxy
label: immich-public-proxy
sub: share links
host: share.example.com

Serves only Immich shared links to the public, validating each one against Immich first.

### app: paperless
label: Paperless-ngx
sub: documents
host: docs.home.example.com
radius: 18

OCR and full-text search for everything dropped into its inbox; an AI script summarises each document.

### app: actual
label: Actual Budget
sub: budgeting
host: budget.home.example.com

Envelope budgeting with bank sync.

### app: actual-api
label: actual-http-api
sub: HTTP wrapper

REST wrapper around Actual's Node library: receipts in, nightly export out.

### app: gokapi
label: Gokapi
sub: file shares
host: files.home.example.com

Expiring download links; uploads stay private, downloads go out via send.example.com.

### app: calibre-web
label: Calibre-Web
sub: ebooks
host: books.home.example.com

Ebook library in the browser, OPDS for reader apps.

### app: openwebui
label: Open WebUI
sub: chat
host: ai.home.example.com

Chat with local models.

### app: backrest
label: Backrest
sub: backup browser
host: backrest.home.example.com

Browse and restore restic snapshots. The timer, not Backrest, runs the backups.

### compute: ollama
label: Ollama
sub: local LLMs
radius: 17

qwen2.5 3B/7B on the GPU; unloads after 5 idle minutes.

### compute: immich-ml
label: Immich ML
sub: CUDA

Face and object recognition for Immich.

### compute: gpu
label: GPU
sub: NVIDIA via CDI
radius: 15

Shared by Ollama, Immich ML and Glances, requested through CDI so a daemon-reload can't strip it.

### compute: speaches
label: Speaches
sub: STT · TTS
host: speech.home.example.com

Whisper and Kokoro behind an OpenAI-compatible API.

### compute: wyoming
label: Wyoming bridge
sub: for Home Assistant

Speaks Wyoming to Home Assistant, HTTP to Speaches.

### compute: backup-job
label: Nightly backup
sub: systemd timer

Database dumps plus restic snapshots of photos, documents and books; `lab restore` brings them back.

### data: photos
label: Photos

The photo library folder.

### data: documents
label: Documents

Paperless media and its inbox.

### data: books
label: Calibre library

### data: immich-pg
label: Immich Postgres

### data: paperless-db
label: Paperless Postgres

### data: restic-repo
label: restic repo
sub: on the backup target

Deduplicated snapshots: 7 daily, 4 weekly, 6 monthly.

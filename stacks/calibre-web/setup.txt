Calibre-Web Automated (https://books.${DOMAIN}): log in as admin / admin123 and change it.
  The library is ${BOOKS_DIR} (created if empty). To add books, copy them into
  ${BOOKS_IMPORT_DIR}: they are imported, then removed from that folder.
  Import options (target format, formats to ignore): Admin -> CWA Settings.
  Then in Admin -> CWA Settings, add pdf and djvu to the formats NOT to convert:
  converting PDFs to EPUB is slow (minutes per file, one file at a time) and
  loses the layout.
  Optional: Hardcover as a metadata source: ./lab config calibre-web HARDCOVER_TOKEN
  (key from https://hardcover.app/account/api), then ./lab up calibre-web.
  E-readers with KOReader (e.g. a jailbroken Kindle): add the OPDS catalog
  https://books.${DOMAIN}/opds to browse and download over Wi-Fi. Use a separate
  Calibre-Web user with only view/download (KOReader keeps the password in plain
  text). Reading progress sync: Admin -> CWA Settings -> "Enable KOReader Sync",
  install the plugin from https://books.${DOMAIN}/kosync and set its server to
  https://books.${DOMAIN} (the plugin adds /kosync itself). A device without
  Tailscale needs a LAN DNS entry (router) pointing books.${DOMAIN} at this
  machine's LAN IP: Caddy answers on 443 there too. Away from home, tethering
  the reader to a phone running Tailscale works as well. OPDS doesn't list DjVu;
  copy those over USB.
